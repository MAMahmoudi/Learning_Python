Django

Overview

Django is a web framework for building database-backed websites in Python. In this chapter you build a complete application step by step: you create a project and an app, define models, add user accounts with login and access control, style the site with Bootstrap, put the code under version control with Git and GitHub, and deploy it to Vercel.
Read the pages in order: each one builds on the project created in the previous one.
