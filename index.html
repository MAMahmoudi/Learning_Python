Learning Python

About

Learning Python is a collection of tutorials and exercises for learning the Python programming language. Each page explains one topic with short, runnable examples.

Suggested Learning Path

  1. Basics: install Python and learn the core language. Practise with the exercises, then check the solutions.
  2. Intermediate: read and write files, handle errors, then learn to write idiomatic Python with functions, generators and classes.
  3. Django: build and deploy a real web application.
  4. Advanced: concurrency, performance, advanced testing and working with other developers.
Type the examples yourself rather than copying them. Change them, break them and read the error messages: that is how the ideas stick.
