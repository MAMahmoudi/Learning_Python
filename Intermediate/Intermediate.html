Intermediate Python

Overview

This chapter assumes you are comfortable with the material in the Basics chapter. It starts with two practical skills every program needs, reading and writing files and handling errors with exceptions, followed by a set of exercises.
The rest of the chapter is about writing idiomatic Python: code that uses the language's features the way they were designed to be used, so it is shorter, clearer and less error-prone. You will learn how to get the most out of lists and dictionaries, functions, comprehensions and generators, classes, and Python's attribute and metaclass machinery, and finish with the fundamentals of testing and debugging.
Work through Files and Exceptions first and try the Files exercises before reading the solutions. The later pages can be read in any order.
